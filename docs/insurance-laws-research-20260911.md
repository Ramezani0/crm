## 1. مبانی حقوقی مشترک

## 2. دیه ۱۴۰۴ (تأییدشده)

### 2.1 ارقام رسمی (قوه قضاییه — مرکز رسانه)

به موجب ابلاغ بخشنامه رئیس قوه قضاییه و در راستای **ماده ۵۴۹ ق.م.ا**، از ابتدای سال ۱۴۰۴:

| نوع | ریال | تومان |
|-----|------|--------|
| **ماه غیرحرام (عادی)** | ۱۶٬۰۰۰٬۰۰۰٬۰۰۰ | **۱٬۶۰۰٬۰۰۰٬۰۰۰** (۱٫۶ میلیارد) |
| **ماه حرام** | ۲۱٬۳۳۳٬۰۰۰٬۰۰۰ | **۲٬۱۳۳٬۰۰۰٬۰۰۰** (۲٫۱۳۳ میلیارد) |

**فرمول تغلیظ یک‌سوم:**

\[
D_{\text{haram}} = D_{\text{normal}} \times \left(1 + \frac{1}{3}\right) = D_{\text{normal}} \times \frac{4}{3}
\]

\[
1.6 \times \frac{4}{3} = 2.\overline{1}33\ \text{میلیارد تومان}
\]

**ماه‌های حرام:** محرم، رجب، ذی‌القعده، ذی‌الحجه (شرط فوت در این ماه‌ها برای تغلیظ).

**رشد نسبت به ۱۴۰۳:** حدود ۳۳٪ (عادی ۱۴۰۳: ۱٫۲ میلیارد تومان؛ حرام ۱۴۰۳: ۱٫۶ میلیارد تومان).

### 2.2 ادعای کاربر (Amir) — تطابق ندارد

| منبع | عادی | حرام |
|------|------|------|
| **قوه قضاییه ۱۴۰۴ (VERIFIED)** | ۱٫۶ میلیارد تومان | ۲٫۱۳۳ میلیارد تومان |
| **USER claim (Amir: 2.1 / 2.8)** | ۲٫۱ میلیارد تومان | ۲٫۸ میلیارد تومان |

> **وضعیت:** ارقام ۲٫۱ و ۲٫۸ میلیارد تومان ادعای کاربر است و با بخشنامه دیه ۱۴۰۴ قوه قضاییه **مطابقت ندارد**. در CRM مقدار پیش‌فرض باید ارقام VERIFIED باشد؛ در صورت نیاز به سناریوی کاربر، آن را به‌صورت فیلد جدا با برچسب `user_override` ذخیره کنید و هرگز با «رسمی ۱۴۰۴» ادغام نکنید.

## 3. فرمول‌های تعدیل حق‌بیمه (CRM)

### 3.1 فرمول پایه (مشترک عمر / بازنشستگی)

\[
P_n = P_0 \times (1+r)^{n-1}
\]

- \(P_0\): حق‌بیمه سال اول (پایه)
- \(r\): نرخ تعدیل سالانه (اعشاری؛ مثلاً ۰٫۱۰ برای ۱۰٪)
- \(n\): شماره سال بیمه‌ای (\(n \ge 1\))
- \(P_n\): حق‌بیمه سال \(n\)ام

**مثال:** \(P_0 = 10{,}000{,}000\) ریال، \(r = 0.10\)، سال ۵:

\[
P_5 = 10{,}000{,}000 \times (1.10)^{4} = 14{,}641{,}000
\]

### 3.2 تعدیل سرمایه فوت (عمر)

\[
C_n = C_0 \times (1+s)^{n-1}
\]

- \(s\): ضریب افزایش سالانه سرمایه فوت

### 3.3 گزینه‌های نرخ — عمر و سرمایه‌گذاری

| منبع | گزینه‌های \(r\) (حق‌بیمه) | گزینه‌های \(s\) (سرمایه فوت) |
|------|---------------------------|-------------------------------|
| **محصول منتشرشده امید کارآفرین** (lifesurance.ir / bimeman.com) | **۰، ۱۰، ۱۵، ۲۰، ۲۵٪** | **۰، ۵، ۱۰، ۱۵، ۲۰٪** |
| **Excel / USER (Amir)** | ۰، ۵، ۱۰، ۱۵، ۲۰، ۲۵، **۳۰٪** | (طبق اکسل پروژه — در CRM به‌عنوان گزینه گسترده نگه دارید) |

**قانون CRM پیشنهادی:**

1. فیلد `premium_escalation_source`: `karafarin_published` | `user_excel`
2. اگر منبع = منتشرشده امید → فقط `{0,10,15,20,25}`
3. اگر منبع = اکسل/Amir → `{0,5,10,15,20,25,30}` و در UI برچسب «گزینه نمایندگی/اکسل — ممکن است با جدول رسمی محصول متفاوت باشد»

### 3.4 بازنشستگی / مستمری

| منبع | نرخ تعدیل حق‌بیمه | نرخ رشد مستمری |
|------|-------------------|----------------|
| **USER (Amir) — قاعده محصول** | **ثابت ۱۰٪** | — |
| **منابع محصول امید بازنشستگی** (bimeh.com و گزارش‌های معرفی طرح) | سالانه تا/معادل **۱۰٪** | مستمری با رشد سالانه **۱۰٪** |

**CRM:** برای محصول امید بازنشستگی کارآفرین، `r` را پیش‌فرض و قفل‌شده روی `0.10` بگذارید مگر الحاقیه رسمی خلاف آن.

### 3.5 توابع پیاده‌سازی (شبه‌کد)

```text
function premiumAtYear(P0, r, n):
  return P0 * (1 + r) ** (n - 1)

function totalPremiums(P0, r, years):
  # مجموع اقساط سالانه بدون سود تقسیط
  sum = 0
  for n in 1..years:
    sum += premiumAtYear(P0, r, n)
  return sum
  # بسته: sum = P0 * ((1+r)^years - 1) / r   اگر r≠0
  # اگر r=0: sum = P0 * years

function financialMinCommitment(diya_haram):
  return 0.025 * diya_haram
```

## 4. شخص ثالث

### 4.1 مبنای قانونی

قانون بیمه اجباری شخص ثالث ۱۳۹۵ (بخش ۱٫۲ بالا) + دیه سالانه (بخش ۲).

### 4.2 اجزای تعهد

| پوشش | مبنای محاسبه ۱۴۰۴ |
|------|-------------------|
| خسارت بدنی شخص ثالث | تا سقف دیه حرام (۲٫۱۳۳ میلیارد تومان) — بدون نیاز به الحاقیه افزایش دیه |
| خسارت مالی | حداقل ≈ ۵۳٫۳۳ میلیون تومان؛ قابل افزایش اختیاری |
| حوادث راننده مسبب | حداقل دیه غیرحرام (۱٫۶ میلیارد تومان) |

### 4.3 حق‌بیمه پایه سواری ۱۴۰۴ (تعرفه بیمه مرکزی — گزارش منابع بازار)

| گروه خودرو | حق‌بیمه پایه تقریبی (تومان) |
|------------|------------------------------|
| کمتر از ۴ سیلندر | ۵٬۶۳۶٬۰۰۰ |
| پیکان، پراید، سپند | ۶٬۶۷۴٬۷۰۰ |
| سایر ۴ سیلندر | ۷٬۸۴۵٬۷۰۰ |
| بیش از ۴ سیلندر | ۸٬۷۸۱٬۰۰۰ |

> ارقام تعرفه را در CRM از جدول سالانه بیمه مرکزی به‌روزرسانی کنید؛ در صورت اختلاف نسخه، `UNKNOWN` تا تأیید فایل رسمی تعرفه.

### 4.4 تخفیف عدم خسارت (پلکانی ۵٪)

\[
\text{Premium} = P_{\text{base}} \times (1 - d)
\]

| سال عدم خسارت | \(d\) |
|---------------|-------|
| ۱ | ۵٪ |
| ۲ | ۱۰٪ |
| … | +۵٪ هر سال |
| ۱۴ | **۷۰٪** (سقف) |

**نکته قانونی عملی:** در قانون جدید، با یک خسارت کل تخفیف صفر نمی‌شود؛ معمولاً بخشی (حدود نیمی) از تخفیف کسر می‌شود — جزئیات دقیق کاهش را از بخشنامه جاری بیمه مرکزی بگیرید (`UNKNOWN` برای درصد دقیق در این سند اگر نسخه ۱۴۰۴ جداگانه ابلاغ نشده در منابع باز).

### 4.5 عوامل تعدیل کاربری (نمونه گزارش‌شده ۱۴۰۴)

- سواری کرایه درون‌شهری: +۱۰٪
- سواری کرایه برون‌شهری: +۲۰٪
- بارکش مواد منفجره: +۵۰٪
- بارکش سوخت: +۲۵٪
- عمومی شهری >۶ نفر: −۵۰٪ (گزارش منابع بازار)

### 4.6 نکات محصول کارآفرین (منابع عمومی)

- پوشش: مالی، جانی ثالث، جانی راننده مقصر
- استثنائات متداول: انفجار هسته‌ای، محکومیت جزایی، خسارت به وسیله/بار مقصر، خسارت خارج کشور

### 4.7 فرمول CRM شخص ثالث

```text
P = P_base(vehicle_class, year)
  * usage_factor
  * (1 - no_claim_discount)
  + late_penalty_days * daily_penalty   # در صورت تأخیر
```

### 6.5 فرمول‌های CRM عمر

```text
# حق‌بیمه سال n
P_n = P_0 * (1 + r) ** (n - 1)     # r ∈ published {0,0.10,0.15,0.20,0.25}
                                     # یا excel {0,0.05,...,0.30}

# UNKNOWN: فرمول دقیق هزینه بیمه‌گری/مرگ‌ومیر داخلی شرکت
# برای نمایش: استفاده از جدول رسمی استعلام شرکت الزامی است
```
